## Inhalte

- Vorstellung Kursstruktur und didaktisches Konzept
- Erhebung eines eigenen Datensatzes, welchen wir im weiteren Verlauf des Kurses verwenden werden.
- Vertrautmachung mit der Statistiksoftware jamovi anhand praktischer Übungen zum Erstellen, Einlesen und Vorbereiten von Daten für die statistische Analyse mit eigenständigem Üben.
- Durchführung einer Datenerhebung parallel zum eigenständigen Üben. Die Daten werden über eine Moodle-Befragung erhoben. Die Daten werden im weiteren Verlauf des Moduls verwendet.
- Jede Person bestimmt Gewicht, Grösse und Farbe von zehn zufällig gezogenen M&Ms.

{{< callout type="important" >}}
**Voraussetzungen**

- Du benötigst für die praktischen Übungen einen eigenen **Laptop** mit der Statistik Software [jamovi](https://www.jamovi.org/). **Ein Tablet (z.B. iPad) ist nicht geeignet**.
- Installiere [jamovi](https://www.jamovi.org/) vorgängig auf deinem Rechner. Die Software ist Open-Source und für macOS, Windows und Linux verfügbar. Wähle das Release **solid** bei den zur Verfügung stehenden Downloads. Dieses Release läuft erfahrungsgemäss stabiler und ist weniger fehleranfällig.

{{< /callout >}}

## Lernziele

{{< callout type="info" >}}
- Die Studierenden importieren, klassieren und codieren Daten in jamovi.
- Die Studierenden berechnen, transformieren und selektieren Daten in jamovi.
- Die Studierenden führen eine einfache deskriptive Analyse in jamovi durch.
{{< /callout >}}
